# Hunt Web Planner v0.6

## Mudanças
- Navegação lateral à esquerda no desktop, horizontal em telas pequenas.
- Textos auxiliares removidos do topo e dos resultados.
- Lista de Pokémon e valores de captura centralizada.
- Planner de Captura funcional com dois filtros, até nove cards e dados reais de `data.json`.

## Atenção ao ranking de Captura
Esta primeira migração usa média aritmética do valor de captura **apenas das espécies dos tipos escolhidos**, com menor média em primeiro lugar e nível como desempate. O ranking ainda precisa ser confrontado com a lógica da aba original no Google Sheets. Não representa probabilidade percentual.

## Publicação
Envie os cinco arquivos do ZIP para a raiz do repositório público do GitHub Pages, substituindo as versões anteriores. Não publique a planilha original ou credenciais.
