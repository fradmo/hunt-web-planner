# Hunt Web Planner 🎮

Um projeto que começou com algumas planilhas para facilitar minhas caçadas e acabou virando um site com várias ferramentas reunidas no mesmo lugar. 😅

A ideia é simples: **gastar menos tempo fazendo contas e mais tempo jogando**. O Hunt Web Planner ajuda a comparar áreas, planejar quests, analisar Pokémon e montar estratégias para enfrentar bosses.

> Projeto independente, feito por fã. Não é uma ferramenta oficial e não tem vínculo com ninguém.
## O que tem no site?

### 🧭 Planejador de Fraquezas e Tasks

Seleciono até **cinco tipos** e vejo quais áreas são mais interessantes para caçar Pokémon com essas fraquezas. Também posso filtrar por faixa de nível e comparar as áreas recomendadas.

Na parte de **Tasks**, a ideia é juntar a escolha da área com o planejamento da quest: informar a quantidade que falta caçar e usar o **Quest Calcs** para estimar o esforço com base nas kills por hora. Também existe a opção de marcar prioridades para ajudar a decidir entre áreas próximas no ranking.

### 🎯 Planejador de Captura

Reúne informações das áreas e dos Pokémon encontrados nelas para comparar opções de captura. Os resultados incluem indicadores como nível e catch médio, além de filtros por tipo e recomendações de áreas.

**Importante:** os valores de catch usados na ferramenta são indicadores do jogo; não devem ser interpretados automaticamente como uma probabilidade percentual de captura.

### ⚔️ Planejador de Bosses

Escolho um boss, seu tier e os afixos disponíveis para consultar os atributos e comparar opções de combate.

O planejador mostra **quatro Pokémon recomendados** e oferece **dois espaços personalizáveis**, nos quais posso testar combinações de Pokémon, golpes, raridades, atributos e outras configurações. O objetivo é ter uma referência prática para montar uma equipe, não prometer uma simulação perfeita de todas as situações do jogo.

### 📊 Planner de Stats

Uma área para explorar e comparar atributos de Pokémon com filtros e critérios padronizados. Ajuda a descobrir espécies interessantes para determinadas funções sem precisar conferir uma por uma.

## Como o projeto começou

No início, eu fazia tudo em **Google Sheets**. Fui organizando bases de Pokémon, golpes, movesets, bosses e áreas, criando fórmulas e automatizações para não precisar repetir as mesmas contas.

Com o tempo, as planilhas ficaram grandes e surgiu a vontade de compartilhar as ferramentas de um jeito mais simples. Foi aí que comecei a migrar a lógica para uma **aplicação web estática**, que abre direto pelo navegador e não exige login.

O projeto continua em evolução. Várias funcionalidades nasceram de problemas que encontrei enquanto jogava — e boa parte das melhorias veio de testar, perceber o que estava confuso e refazer até ficar mais útil.

## O que tem por trás

- **HTML, CSS e JavaScript** para a interface e as regras do site.
- **Bases de dados estruturadas** para Pokémon, áreas, golpes, movesets e bosses.
- **Fórmulas, filtros e rankings** para transformar os dados em recomendações.
- **Google Sheets** como ponto de partida para organização, conferência e prototipagem.
- **GitHub Pages** para publicar o site de forma simples.
- Interface pensada para **português, inglês, espanhol e chinês (traduzido por IA)**.

Mais do que montar uma página, meu foco foi aprender a **organizar dados, transformar regras em cálculos e apresentar resultados de um jeito que realmente ajude alguém a tomar uma decisão**.

## Como usar

1. Abra o site publicado pelo GitHub Pages.
2. Escolha o planejador no menu.
3. Ajuste os filtros ou selecione o Pokémon/Boss desejado.
4. Compare os resultados e use as recomendações como apoio para o seu planejamento.

Não é necessário criar conta nem instalar nada.

## Estado do projeto

🚧 **Em desenvolvimento.** Ainda estou revisando cálculos, refinando o layout e corrigindo detalhes de compatibilidade e exibição. Alguns resultados dependem das bases e das regras específicas do jogo, que podem mudar.
